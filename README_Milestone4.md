# Milestone 4 — Causality, Seriousness, and Expectedness

## Deliverables
- `PV_Causality_Seriousness_Expectedness_Report.docx` — case-by-case rationale and summary.
- `PV_Causality_Seriousness_Expectedness_Checklist.csv` — spreadsheet-ready case matrix.

## Assessment approach
- Causality is reviewed qualitatively using WHO–UMC principles.
- Naranjo scores are not fabricated where required inputs are missing.
- Seriousness is based on reported regulatory criteria; hospitalisation cases are flagged for verification.
- Expectedness is left **Not assessable** because the task's expectedness reference document was not available in the files reviewed.

## Important limitation
This is a de-identified training exercise, not a real-patient safety assessment or regulatory submission. Add the task's expectedness reference document and revise the expectedness fields before presenting the work as final.

## Cases covered
PV-101 (nausea), PV-102 (loss of consciousness), PV-103 (mild rash), and PV-104 (appendicitis).
